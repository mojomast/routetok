          DASHBOARD GUIDE
          How Everything Works
          
        
          
          
          Support Agent
          Diagnoses routing, explains behavior, helps with onboarding, and prepares configuration proposals. Explicit intents override automatic detection. Proposals always require review and confirmation.
          
          
          Model Workspaces
          Chat and Design workspaces are not available in this dashboard. RouteTok Support is the dashboard's only conversational workspace.
          
          
          API Setup
          The Connect Applications panel documents client endpoints and authentication. Provider credentials remain write-only and are managed separately from the client proxy key.
          
          
          Speech
          Record or upload audio for transcript review, and use Listen on completed results. Audio remains ephemeral, transcripts never auto-send, and the initial TTS catalog is restricted to confirmed free models.
          
          
          Saved
          Support runs are stored in IndexedDB. Older Chat and Design records remain available as legacy archives, but those workspaces are no longer provided by this dashboard.
          
          
          Live Flow
          Shows model, route phase, attempts, elapsed time, TTFT, estimated tokens, and tokens per second. The hold slider controls how long finished rows remain.
          
          
          API Keys
          Keys are write-only. They are sent to this router, stored under owner-only filesystem permissions, never returned to the browser, and take effect for future requests.

          Provider API Keys
          Values are write-only and never displayed again. Stored overrides use DATA_DIR/secrets with owner-only permissions.
