# Security Policy

Please report vulnerabilities privately through GitHub's private vulnerability reporting for `mojomast/routetok`. Do not open a public issue containing API keys, dashboard/proxy tokens, prompts, provider responses, request bodies, filesystem paths, or unredacted runtime data.

The latest release on `main` is supported. RouteTok is local-first software; public Internet exposure without authentication, TLS, and network restrictions is outside the supported threat model.
