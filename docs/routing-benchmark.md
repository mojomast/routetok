# Routing benchmark and evidence gate

Research: WebXNG/SearXNG discovery found LLMRouterBench (https://arxiv.org/html/2601.07206v1), which warns that sophisticated routers may not beat a best-single-model baseline. RouteLLM's official README (https://github.com/lm-sys/RouteLLM) explicitly calibrates thresholds against a workload. TypeSafe confidence documentation distinguishes classification certainty from task success. Extraction tool was unavailable; primary pages were fetched directly using curl.

Implemented: `src/routing-benchmark.ts` scores coverage, unconditional task success (abstentions count as unsuccessful), selective failure, Wilson lower confidence bound, nearest-rank p50/p95 latency, total cost and cost per successful task. Unknown classifier charges yield null total cost, never zero. No claims of net savings without known bills. `scripts/evaluate-jev.ts FILE` replays the exact-answer subset of the prior live paired JSON; it never sends network requests or executes generated code.

Replay actual run: 5 objectively scorable tasks per route. jev-auto 4/5, coverage .8; DeepSeek 5/5, coverage 1. Lower bounds .3755 and .5655 show both samples are far too small for reliable certification. p50 1284 vs 1548 ms; p95 17693 vs 11725 ms. All examples are DEVELOPMENT because already inspected, not heldout. This is a regression baseline, not a public benchmark score. Other tasks require additional independently specified validators and are not silently graded correct.

Optional policy evidence: `{qualityFloor:0.9,rows:[{model:'provider:model',family:'coding',passed:100,total:100,meanTotalUsd:0.001}]}`. Numbers here are schema examples, not measured claims. Within operator-approved eligible models, selection uses lowest mean cost only when the per-family Wilson lower bound meets the quality floor. Tiny samples fail closed with jev_insufficient_quality_evidence. Default behavior remains unchanged without evidence. Uncertainty fallback remains an explicit operator escape hatch, not a quality-certified selection. No evidence generated by these tiny experiments is activated automatically.

Operator must supply reviewed development evidence, including all failures and comparable task distribution; current schema does not authenticate evidence provenance, revisions, confidence coverage under correlated tasks or dataset leakage. Wilson nominal 95% bounds assume independent Bernoulli trials and are not simultaneous multiple-model guarantees. No observed success rate guarantees correctness on a new request.

Next evaluation protocol: freeze a versioned task inventory before running; split by source/template/session, not paraphrase; keep heldout private until thresholds frozen. Run every candidate, fixed flagship, cheapest fixed model, static family route and Jev on identical cases with shuffled order and repeats. Preserve raw usage, provider/revision, verifier outcomes and finish reasons. Score extraction against source, raw-code syntax/behavior only in a real sandbox, JSON schemas strictly, and subjective writing with blinded human/rubric review. Report family slices, output-format pass rates, calibration of independently predicted success (NOT family confidence), unnecessary abstention, escalation, TTFT, retries and fully loaded cost. Compare paired success and cost with intervals; do not deploy until quality noninferiority and cost benefit hold. No output-retry pipeline or live benchmark runner is introduced here.
