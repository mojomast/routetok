# Multi-file repair pilot, two passes

Four synthetic two-module projects, two development and two frozen heldout task IDs. Clear written contracts, supplied buggy files, visible application tests and separate scoring tests. Broken baselines verified to fail visible tests; all reference patches pass both test sets before inference. Frozen commit095903b. No policy tuning between partitions or repeats; repeats after initial inspection are development evidence, not new holdout. Small fixtures, NOT real repository repairs or statistically robust production evaluation.

24 real requests,8192 allowance, hard120s HTTP deadline, no provider fallback, three policies. Across eight task trials each: Mercury4/8,$0.00264012; Gemini6/8,$0.10895775; cascade7/8,$0.00271636. All bills known. Cascade NEVER escalated: all its independent Mercury attempts passed visible tests, one failed scoring. Its apparent advantage is generation variability, NOT rescue benefit. Do not rank cascade as a proven routing winner. Per-request cost and duration retained; test wall time included in successful attempt timing but hidden scoring outside timing.

Mercury-only consistently missed blank query values and nested-interval preservation despite explicit requirements. Gemini consistently passed interval scoring, but failed query JSON formatting in both passes (one length finish, one stop). This is a small observed specialist opportunity on interval task, confounded by separate cascade Mercury successes. Need more repeats and fresh tasks before classification.

Recommendation: improve application tests with independently derived contract properties (blank values, nested intervals, mutation invariance) BEFORE relying on fallback. Run structured-output supported response mode separately for Gemini to distinguish delivery failures from solver capability. Then evaluate visible-failure-triggered escalation on NEW fixtures, preserving old scores. No Jev promotion. Keep cheap explicit-model default option; current evidence does not support paying Gemini on every request.

Sandbox is Docker with no network, mounts, credentials, unprivileged user and resource limits. Candidate source is written only to tmpfs after exact filename validation. Hidden tests never supplied in prompts or retry messages, but live in same candidate interpreter during scoring; not resistant to deliberate malicious test bypass. Public synthetic responses intentionally retained. Full application TypeScript suite not rerun; Python reference checks and live integration exercised.
