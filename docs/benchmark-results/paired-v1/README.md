# Paired frozen-policy pilot: evidence, not proof

Research via WebXNG/SearXNG and primary pages: https://arxiv.org/html/2607.03436 warns single-draw best-of-model oracle inflates reproducible specialist advantage. RouteLLM https://github.com/lm-sys/RouteLLM recommends workload-specific threshold calibration. Therefore freeze routing before inspecting answers, repeat generations, compare fixed cheap and strong baselines, and split by source/template. Do not select a model using the same outcomes used to score it.

Executed eight newly authored medium-complexity cases x four live models plus eight live Jev decisions. Policy frozen before generation: explicit-text-v2, .8 confidence, GLM writing, Qwen Flash coding, DeepSeek reasoning/uncertainty. Decision recorded before all candidates generated in parallel. This is counterfactual replay using live decisions and candidate calls, not another live proxy dispatch benchmark. No policy tuning after viewing these results. Cases overlap known task styles, so this is a development pilot, not representative independent holdout.

Strict exact-string or parsed-JSON grading (no Markdown stripping): routed replay 8/8, DeepSeek 8/8, Qwen Flash 8/8, GLM 5/8, Gemini Lite 2/8. Gross downstream costs router $.00098285925 vs DeepSeek $.0010738: 8.469% difference. Jev cost unknown, so net savings remains null. Experimental generation total $.0036206636, Jev usage 4942 tokens. Lower listed token prices do not guarantee cheaper completions: fixed Qwen cost $.00155686, exceeding DeepSeek here. Model-specific verbosity/reasoning matters.

Statistical gate: zero discordant losses in eight pairs has a one-sided exact 95% upper loss-probability bound of .312344 under independent Bernoulli sampling. This is NOWHERE NEAR proof of equal quality. For a predeclared 2% tolerated degradation, even observing zero losses requires at least 149 independent representative pairs to bound discordant loss probability below 2%; failures require larger samples/proper power analysis. Repeated paraphrases do not constitute independent pairs. Fixed-sample design avoids optional-stopping bias. This conservative discordant-loss bound ignores beneficial discordances; a powered paired noninferiority design can use both.

Release proof protocol: preregister quality margin, cost target, workload mixture, sample size and primary metric. Split development/calibration/heldout by source/session. Collect repeated candidate outputs to distinguish reproducible advantage from lucky samples; freeze policy, revisions, provider and supported reasoning settings. Count all failures/abstentions in intention-to-route quality. Compare paired quality differences with one-sided intervals and cost differences with source-cluster bootstrap; report family slices and correct multiple comparisons. Include full classifier, retry, verifier, fallback, cache and generation charges; report missing bills explicitly. Require quality noninferiority AND positive net savings interval; never infer equivalence from a nonsignificant difference. Benchmark best fixed candidate and static family routing as well as flagship. Production shadow/canary evaluates drift and privacy separately.
