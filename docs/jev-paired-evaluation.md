# Paired live evaluation and Jev dashboard

Nine synthetic tasks, each sent once to jev-auto and once explicitly to deepseek/deepseek-v4.1-flash via real Routetok/OpenRouter. 256 output token cap, sequential order (router then reference); no randomization, repeated trials or model-judge claims. Jev-1.13.0, same operator family mapping as prior smoke. This is an exploratory sample, NOT a held-out performance benchmark.

Results: seven routed completions, two abstentions. Reference answered all nine, including clarification for ambiguous 'Fix it'. Routed abstention on 'Fix it' was appropriate; email extraction also abstained despite adequate information. Coding returned fenced Python when raw code was requested (strict formatting failure); reference returned raw code. Debugging (list length), arithmetic, logic, translation and rewrite outputs were substantively correct by inspection; no generated code executed. Injection asking to ignore routing constraints remained on the permitted cheap writing route. One case does not establish injection robustness.

Measured downstream cost: routed $0.00016905; all nine reference completions $0.000958865. Matched seven reference completions cost $0.000627935: gross difference 73.0784%. Do not count refused tasks as successful savings. Excludes Jev dollar charges, quality loss, retries and verification. DeepSeek provider selection/prices and reasoning token use varied; even identical selected models had different costs, so not all difference is routing benefit. Median matched response latency 1309 ms routed / 1548 ms reference; sequential tiny sample, no statistical superiority claimed. Jev mean latency 329.56 ms, 4834 reported tokens. Total OpenRouter evaluation spend $0.001127915; cumulative with prior smoke $0.001242315. Cumulative reported Jev usage 6941 tokens; prior invalid 422 response reported no usage.

## Dashboard

Authenticated GET /admin/api/jev and dashboard status panel show last 500 classifier attempts since restart, selected vs failed/abstained, token usage, mean classifier latency, and recent decisions without prompts. Set JEV_BASELINE_INPUT_USD_TOKEN and JEV_BASELINE_OUTPUT_USD_TOKEN to verified reference token prices. Missing prices render unknown, not fabricated savings. The comparison joins classifier request IDs to actual Routetok metric samples and reprices the observed downstream tokens. This is explicitly SAME-TOKEN ESTIMATION, not execution of the reference model; actual reference output and reasoning length can differ greatly. Net savings remains null until Jev billing can be accounted for. Negative gross differences remain negative.

Limitations: in-memory classifier window, no persistence or billing-grade completeness for malformed/unknown outcomes; errors and abstentions grouped; no paired-evaluation import UI; no calibrated success estimate. The panel does not display the exploratory paired percentage as a production savings claim. Live API checks exposed an initial metrics shape mismatch; corrected join from id/usage to requestId/inputTokens/outputTokens/costUsd and added regression test. Typecheck and all 275 tests pass.
